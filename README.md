# Project Hyena Viewer

A modern, different take on the Second Life viewer, built on Firestorm. Project Hyena aims to run smoothly on any PC, from small, older laptops to powerful new desktops. Windows only for now.

**Status: 0.1.0 alpha (Early Build).** Expect rough edges.

## Download
Get the installer from the [Releases](../../releases) page. The installer is not code-signed yet, so Windows SmartScreen may warn you. Choose "More info" then "Run anyway".

## Report a problem or suggest something
Use the [Issues](../../issues) tab and pick Bug report or Feature request.
