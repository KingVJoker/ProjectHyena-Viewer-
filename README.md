# Project Hyena

**Project Hyena is an independent third-party viewer for Second Life, built around a modern interface and smoother performance, with a companion launcher for quick sign-in.**

> **Status:** Alpha 0.1.0 (Early Build). Windows only for now. Releases and a Discord community are coming soon.
>
> **Platform:** Project Hyena currently targets **Windows (64-bit)** only. Mac and Linux builds are something we hope to add later, but there is no timeline yet. Follow this repository for updates.

## Based on Firestorm and Second Life

Project Hyena is derived from the [Firestorm Viewer](https://www.firestormviewer.org) (Phoenix Firestorm Project, Inc.), which is in turn derived from the official [Second Life Viewer](https://github.com/secondlife/viewer) by Linden Lab. The viewer codebase has been open source since 2007 and is available under the LGPL license (see [LICENSE](LICENSE)).
